SDDM Authelia Passkey

Approve your Linux login on a phone with a passkey. OIDC Device Authorization handles the remote approval, while the normal password path remains intact as the fail-safe fallback.

Install on Debian 13 Latest release Roadmap
Overview

Passwordless approval without sacrificing recovery

The broker performs the long-running OIDC device flow outside SDDM. A native PAM module consumes a root-owned, short-lived, single-use approval marker. If no valid approval exists, authentication falls through to the normal password path.

Features

Security-first login plumbing

Built for a login stack where failure must be boring, explicit and recoverable.

📱

Smartphone / passkey approval

OIDC Device Authorization with WebAuthn/passkey verification at the identity provider.

🔑

Password stays intact

The PAM integration is additive. Missing or failed approval keeps the normal password path available.

🧭

Provider-neutral OIDC

Authelia by default, with generic discovery-based support for standards-compliant providers.

🧬

Identity binding

OIDC proves authentication; NSS/SSSD remains authoritative for the Unix identity.

🗝️

Optional FIDO2/U2F

Local hardware-key login through the upstream pam_u2f path, kept separate from remote OIDC.

🧰

Recovery tooling

Preflight, postflight, doctor, rollback and break-glass tooling designed to avoid login lockout.

👛

KWallet hand-off

Optional best-effort KWallet unlock over a separate root-only AF_UNIX secret service.

🛡️

Supply-chain controls

Signed Debian packages, checksums, SBOMs, CodeQL, dependency review and hardened build flags.

Installation

Debian 13 APT repository

Install the signed package from the project APT mirror, then run the documented preflight before enabling PAM integration.

curl -fsSL https://apt.s3-dev.ovh/trixie-KEY.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/sddm-authelia-passkey-repo.gpg
echo "deb [signed-by=/etc/apt/trusted.gpg.d/sddm-authelia-passkey-repo.gpg] https://apt.s3-dev.ovh trixie main" | sudo tee /etc/apt/sources.list.d/sddm-authelia-passkey.list
sudo apt update
sudo apt install sddm-authelia-passkey

Fail-safe PAM integration

Single-use marker model
