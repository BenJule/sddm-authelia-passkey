# Code of Conduct

## Our commitment

This project aims to provide a respectful, technically rigorous place to build and discuss secure Linux authentication tooling.

## Expected behaviour

Please:

- discuss ideas, code and evidence rather than people;
- give specific, actionable technical feedback;
- respect different experience levels and backgrounds;
- accept correction when new evidence appears;
- protect privacy and never post credentials, tokens or private infrastructure details;
- follow the project's responsible-disclosure process for security issues.

## Project spaces

This policy applies to repository issues, pull requests, reviews, discussions and other spaces used to represent this project.

## Moderation

The maintainer may edit or remove off-topic or abusive content, lock conversations, issue warnings, or restrict participation when necessary to keep the project safe and productive.

For moderation concerns, contact the maintainer privately through GitHub. Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be reported in a public issue.

## Attribution

This policy is inspired by the Contributor Covenant and adapted for this project's small, security-sensitive maintainer model.
